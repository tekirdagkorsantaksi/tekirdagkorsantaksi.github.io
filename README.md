# Tekirdağ Korsan Taksi

Tekirdağ korsan taksi hattında iki ayrı düzen vardır: kuzeyde sanayi, güneyde sahil. Çorlu'daki havalimanı Çorlu'dan 14, Çerkezköy'den 37, il merkezi Süleymanpaşa'dan 56 kilometredir. Sefer sayısı az olduğunda yolcu İstanbul Havalimanı'na taşınır.

Çerkezköy, Kapaklı ve Ergene'deki fabrikaların üç vardiyası hattın en düzenli işidir. Yazın Şarköy ve Mürefte'ye, bağ yoluna gidilir; Şarköy 135 kilometre, 2 saat 13 dakikadır. Liman ve üniversite Süleymanpaşa'nın günlük duraklarıdır.
